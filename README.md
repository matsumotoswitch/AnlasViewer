# AnlasViewer

NovelAIの画面上部ヘッダーにあるAnlas合算表示を、**「定期購入分」**と**「有償分」**に分割して2段センタリングで表示するブックマークレットです。

```text
【 変換前 】  Anlas: 15,470 [Icon]  |  +

【 変換後 】    定期      有償       合計
             5,628  +  9,842  =  15,470 [Icon]  |  +
```

GitHub Pagesでホストした外部スクリプト（`anlas-viewer.js`）を動的に読み込む**ローダー形式**を採用しています。本体コードをGitHub上で更新すれば、ブラウザ側のブックマークレットを再登録することなく、常に最新機能・修正が自動反映されます。

---

## 主な特徴

* **上下2段の自動センタリングレイアウト**
  * 上段（`定期` / `有償` / `合計`）と下段（`数値`）が各カラムごとに中央揃えされます。
  * 定期Anlasが `0` の場合でも、「定期」の横幅内で `0` が綺麗にセンタリングされます。
* **リアルタイム自動追従（Anlas消費の即時反映）**
  * **Fetchインターセプト**: 画像生成などのAPI完了をフックし、生成直後に最新の残高をバックグラウンドで自動再取得します。
  * **MutationObserver**: ページ遷移や画面の再描画によって表示が戻ってしまった場合でも、自動的に分割表示を維持します。
* **NovelAI公式機能との完全共存**
  * 余計な黄色い元の合算値テキストのみをピンポイントで非表示化し、公式の「＋」ボタンやアイコンはそのまま保持します。
  * ヘッダーのAnlas枠をクリックした際、NovelAI公式の「Purchase Anlas（Anlas購入）」画面も通常通り開きます。
* **ワンタッチ手動リフレッシュ**
  * ヘッダーの表示をクリックするか、ブックマークレットを再度実行することで、いつでもAPIから最新残高を再取得できます。
* **タブ復帰時の自動同期**
  * 別タブでの作業からNovelAIのタブに戻ってきた際（`visibilitychange`）にも自動で最新残高を同期します。

## 導入方法（ブックマークレットの登録）

### 方法A: 配布ページからドラッグ＆ドロップ（推奨）

GitHub Pagesを有効化している場合、公開ページ（`https://<ユーザー名>.github.io/AnlasViewer/`）を開き、ページ上の **「AnlasViewer」ボタンをブラウザのブックマークバーにドラッグ＆ドロップ** するだけで登録完了です。

### 方法B: 手動でブックマークに追加

1. ブラウザのブックマークバーを右クリックし、**「ページを追加」**または**「ブックマークを追加」**を選択します。
2. 名前に `AnlasViewer`（任意）と入力します。
3. URL欄に以下のコードを貼り付けて保存します：

```javascript
javascript:(function(){var s=document.createElement('script');s.src='https://matsumotoswitch.github.io/AnlasViewer/anlas-viewer.js?'+Date.now();document.head.appendChild(s);})();
```

> **Note**: 末尾の `?+Date.now()` はキャッシュバスターです。GitHub側でスクリプトが修正・更新された際も、ブラウザの古いキャッシュに邪魔されず常に最新版が読み込まれます。

## 使い方

1. [NovelAI](https://novelai.net/) にアクセスし、ログインします。
2. 登録した **AnlasViewer** ブックマークレットをクリックします。
3. ヘッダーの「Anlas: 〇〇」が **「定期 / 有償 / 合計」の2段内訳表示** に切り替わります。
4. その後は自動で常駐し、画像生成によるAnlas消費や画面遷移にもリアルタイムで追従します。
5. 最新状態を手動で再取得したい場合は、ヘッダーの表示をクリックするか、再度ブックマークレットを実行してください。

## 技術仕様・アーキテクチャ

### 1. 認証トークンの安全な取得
NovelAIがログイン時にブラウザの `localStorage.getItem('session')` に保存しているJSONデータを安全にパースし、認証トークン（`auth_token`）を取得してBearer認証ヘッダーを組み立てます。

### 2. 残高取得APIのエンドポイント
* **エンドポイント**: `GET https://image.novelai.net/user/subscription`（予備: `/user/data`）
  * ※NovelAI公式のサーバー仕様変更により、残高・サブスク関連エンドポイントは `api.novelai.net` から `image.novelai.net` へ移行されています。旧ホスト宛てはHTTP 400が返るため、本ツールでは `image.novelai.net` を優先指定しています。
* **取得データ**:
  * `trainingStepsLeft.fixedTrainingStepsLeft`: 定期購入枠（サブスクリプションにより毎月付与されるAnlas）
  * `trainingStepsLeft.purchasedTrainingSteps`: 有償枠（都度購入したAnlas）

### 3. 表示レイアウト & センタリング設計
* **Flexbox 2段カラム構成**:
  各項目（定期・有償・合計）を `display: inline-flex; flex-direction: column; align-items: center;` で構成。
  これにより、数値の桁数に関わらず「定期」「有償」「合計」のラベルが数値に対して常に水平中央揃えになります。値が `0` の場合でも、ラベル幅の中で綺麗に中央配置されます。
* **演算子の配置**:
  記号（`+` および `=`）は下段数値のベースラインに自然に揃うよう、下揃え（`margin-top: auto`）で配置しています。

### 4. DOM特定と公式UIの保護
* **ヘッダー要素の限定走査**:
  画面最上部のバー領域（`top < 80px`）にある要素のみを対象にし、購入モーダル画面（`Purchase Anlas`）などの他画面要素を決して誤認しないよう座標・属性の二重判定を行っています。
* **黄色い合算値のピンポイント非表示**:
  ヘッダーの角丸枠内に残存する古い黄色い合算値（例: `15470 [Icon]`）のみを特定して非表示化。右端の「＋」ボタンやメニューアイコンは保護し、コインアイコンのみAnlasViewerの末尾に引き継ぎます。
* **イベント伝播の維持**:
  クリック時に残高を更新しつつ、イベントの伝播（`e.stopPropagation()`）を呼ばない設計としているため、クリック時にNovelAI本来の「Purchase Anlas」画面も問題なく開きます。

### 5. 無限ループ & 多重実行の防止
* **書き換え中フラグ（`isMutating`）**: 自スクリプトによるDOM変更時にフラグを立て、`MutationObserver` の自己検知ループを遮断。
* **カスタム属性ガード**: 反映済み要素に `data-anlas-view="true"` を付与し、かつ内容一致判定により重複再描画を抑止。
* **多重起動ガード**: `window.anlasViewerActive` により、複数回クリックされてもObserverが多重登録されず、最新残高の再取得（リフレッシュ）として安全に機能します。

## コンソール用デバッグコマンド

ブラウザの開発者ツール（F12）のコンソールから以下の関数を実行できます：

```javascript
// 最新残高をAPIから即時再取得して表示を更新
window.anlasViewerRefresh();

// 監視・インターセプトを完全に停止し、DOMを元の状態に復元
window.anlasViewerCleanup();
```
